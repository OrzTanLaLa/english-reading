英语朗读 · 隐私政策

生效日期：2026-11-04

适用应用：英语朗读（包名 com.orztan.englishreading）

本应用是一款在 HarmonyOS 设备上运行的英语精读工具，帮助你把课本拍照转为文字、朗读并逐词高亮、

在阅读中随时提问并把生词记入语汇录。我们尽量少收集数据，所有课程内容默认只保存在你自己的设备上。

一、我们处理哪些信息

信息何时产生用途是否离开设备
你拍摄或从图库选择的课本照片导入课文时发送到云端做文字识别（OCR）是，仅用于本次识别
识别出的课文文本导入后合成朗读音频、作为提问上下文文本会发送到云端合成与问答
你的语音提问录音点击麦克风时发送到云端识别成文字是，仅用于本次识别
你输入的文字问题打字提问时发送到云端获取回答是
合成音频、词级时间戳、语汇录应用自动生成本地朗读与复习否
API Key（百炼 / DeepSeek）你在设置页填写调用云端服务的凭证否，仅存本机

不收集：通讯录、短信、位置、设备标识符（IMEI/OAID）、剪贴板、已安装应用列表、使用行为统计。

不含广告、不含第三方统计 SDK。

二、第三方服务

为实现识别、朗读与问答，应用会把当次请求所需的最小内容发送给以下服务：

服务提供方收到的内容用途
文字识别（qwen3-vl-plus）阿里云百炼（DashScope）你选择的课本照片OCR
语音合成（qwen-audio-3.1-tts-flash）阿里云百炼（DashScope）课文文本生成朗读音频
语音识别（qwen3.8-omni-flash）阿里云百炼（DashScope）你的语音提问录音把语音转成问题
问答（deepseek-chat）深度求索（DeepSeek）课文全文、当前句、你的问题生成回答

这些服务由其提供方按其隐私政策处理数据，应用不做长期存储，也不把它们用于训练。

API Key 由你自行申请并填写，应用不内置任何密钥。

三、数据保存在哪里

  • 课程（原文、原图、音频、语汇录）保存在本机应用沙箱内，不会上传到我们的服务器；
  • API Key 保存在本机应用偏好设置中；
  • 卸载应用或删除课程会同时删除对应数据；
  • 你可以在「设置 → 导出文库数据」自行导出全部数据（zip）备份。

四、权限说明

权限用途是否可拒绝
麦克风（ohos.permission.MICROPHONE）语音提问可，拒绝后仍可打字提问
网络（ohos.permission.INTERNET）调用上述云端服务可，拒绝后无法识别/朗读/问答
相册 / 文件通过系统选择器选择照片与导出 zip无需额外授权，仅访问你主动选择的文件

五、你的权利

  • 随时删除单门课程（库页菜单 → 删除）；
  • 随时修改或清空 API Key（设置 → 修改 API Key）；
  • 卸载应用以删除全部本地数据。
