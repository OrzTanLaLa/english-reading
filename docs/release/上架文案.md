## 应用名称

```
英语朗读
```

## 一句话简介（≤ 30 字）

```
拍下英语课文，即刻朗读、逐词高亮；随时提问，生词自动记入语汇录。
```

## 应用介绍

```
英语朗读是一款面向英语精读的辅助工具，帮助你把手里的纸质课本变成可以听、可以问、可以复习的材料。

【拍照导入】
拍摄或从图库选择课本页面，自动识别成可编辑的英文文本，自动去掉段首编号并按段落整理；识别结果可以手动修改。

【朗读与逐词高亮】
云端语音合成后播放，按词级时间戳逐词高亮；点击任意单词即可跳到该处继续播放。支持暂停、续播与进度拖动。

【随时提问】
暂停后可以打字或直接说话提问，例如「tuck away 是什么意思」「这句话怎么翻译」。回答会给出一句简洁的中文解释，
并附上这句话的中文翻译；问的是引申义时还会说明原义并给例句。所有问答会自动整理进本课的语汇录。

【语汇录】
按「单词 / 搭配 / 其他」分类记录，包含语境原文、你的问题和回答，随时回看复习。

【数据自持】
全部课程数据保存在本机，可一键导出成 zip 备份，也可从 zip 导入恢复；换设备或误删都能救回来。

本应用不含广告、不做用户画像、不含第三方统计 SDK。识别、合成、语音识别与问答由阿里云百炼与 DeepSeek 提供，
用户需在设置中自行填写自己的 API Key。
```

## 权限使用说明

```
麦克风：仅在用户点击「话筒」按钮时录音，用于把语音提问转成文字；不在后台录音，不保存录音文件。
网络：用于调用云端文字识别、语音合成、语音识别与问答服务。
相册/文件：通过系统文件选择器访问用户主动选择的照片，用于导入课文；导出时由用户选择保存位置。
```
