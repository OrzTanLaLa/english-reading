## 三、应用介绍

英语朗读是一款面向英语精读的辅助工具，主要能力：

1. **拍照导入**：拍摄或从图库选择课本页面，自动识别成可编辑的英文文本（自动去掉段首编号、按段落整理）；
2. **朗读与高亮**：云端语音合成后播放，按词级时间戳逐词高亮，点任意单词即可跳转到该处；
3. **随时提问**：暂停后可以打字或直接用语音提问（如「tuck away 是什么意思」），
   回答会给出中文解释、所在句的翻译，并自动记录到本课的语汇录；
4. **语汇录**：按「单词 / 搭配 / 其他」分类记录，可随时回看；
5. **数据自持**：全部课程数据保存在本机，可一键导出成 zip 备份，也可从 zip 导入恢复。

本应用不包含广告、不做用户画像、不含第三方统计 SDK。

## 四、托管隐私政策

AGC 要求提供**可公开访问的 URL**。最省事的两种做法：

1. **GitHub Pages**（推荐，免费且稳定）：
   - 仓库 `OrzTanLaLa/english-reading` 已存在 → 新建分支 `gh-pages`，放入 `index.html`（内容为 `docs/release/privacy-policy.md`）；
   - Settings → Pages → Source 选该分支 → 得到 `https://orztanlala.github.io/english-reading/`；
2. 或用 Gitee Pages / 自己的域名托管同一份 Markdown。

> 注意：直接给 GitHub 的 `blob` 链接可能被审核认为“不是正式隐私政策页”，建议用 Pages。

## 四之二、构建上架包（`.app`）

```powershell
pwsh -File scripts\build-release.ps1
# 产物：app\build\outputs\default\app-default-signed.app（约 1.8 MB）
```

脚本会**临时**把 product 的 signingConfig 从 `default`（debug）切成 `release`，构建完自动还原——
因为 DevEco 只把 release 签名写成 `signingConfigs` 里的一条，product 仍指向 debug；
给模块加 `applyToProducts` 会被 schema 拒绝（实测 `00303038`）。

上架包内容核对（解压 `.app` 看 `pack.info`）：

```
bundleName: com.orztan.englishreading
versionCode: 1000001 / versionName: 1.0.0
deviceType: tablet / phone / 2in1
releaseType: Release
```
